## 📂 Repository Structure

/backend → Spring Boot microservices (REST APIs, business logic)
/frontend → React application (UI & client-side logic)
/infra → Terraform IaC for provisioning cloud resources

## 🚀 Features

- **Spring Boot**: Scalable backend APIs
- **React**: Dynamic and responsive frontend
- **Terraform**: Cloud infrastructure automation
- **Environment-specific configurations**: Dev, staging, prod
- **CI/CD pipeline integration**: Ready for automation

## ⚡ Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/girdharv18/SOT.git
cd SOT
```

### 2️⃣ Backend (Spring Boot)

```bash
cd backend
./mvnw spring-boot:run
```
The backend will start on [http://localhost:8080](http://localhost:8080)


### 3️⃣ Frontend (React)

```bash
cd frontend
npm install
npm start
```
The frontend will start on [http://localhost:3000](http://localhost:3000)


### 4️⃣ Infrastructure (Terraform)

```bash
cd infra
terraform init
terraform plan
terraform apply
```

### 🔧 Prerequisites

- Java 17+
- Maven or Gradle
- Node.js (>= 18)
- npm (>= 9)
- Terraform CLI (>= 1.0)
- Git
